<p><sub><strong>01 / HEALTH TECH</strong> &nbsp;·&nbsp; PRIVACY BY DESIGN</sub></p>

<h3>🩺 AyuScout AI — Pharmacovigilance Intelligence Platform</h3>

A React dashboard for adverse-event review, safety alerts, KPIs, drug exploration, and report management, backed by FastAPI REST APIs. The workflow emphasizes safer review through patient-identity masking, drug-name normalization, and ICH E2B(R3) XML report export.

<p>
  <img src="https://skillicons.dev/icons?i=react,fastapi,sqlite&theme=dark" height="38" alt="React, FastAPI and SQLite" />
</p>

<p><sub>CORE CAPABILITIES</sub></p>

- Patient-identity masking and PII detection
- Drug-name normalization with fuzzy matching
- ICH E2B(R3) XML report exports

- Risk heatmaps, geospatial alerts, and scenario planning for suppliers, routes, inventory, and procurement
